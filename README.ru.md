## Что это такое

Сфокусированное **приложение для строки меню** macOS, которое показывает, сколько от вашего **лимита использования Codex (ChatGPT) осталось** - для **каждого вашего аккаунта одновременно**. Никакого переключения между аккаунтами, никаких дашбордов, никаких аккаунтов, спрятанных за кликами. Взглянули на строку меню, увидели, сколько осталось, и вернулись к работе.

Оно делает ровно одну вещь и при этом не мешается под ногами.

## Зачем ещё один трекер использования?

Большинство трекеров читают локальный Codex CLI, который залогинен в **один** аккаунт за раз - поэтому они всегда могут показать только его. Переключатели показывают один активный аккаунт и заставляют вас его менять. **OnlyLimits хранит собственные учётные данные каждого аккаунта и опрашивает их независимо**, так что все ваши аккаунты видны *одновременно* - именно то, что на удивление трудно найти.

И оно создано, чтобы раствориться в системе: бинарник в **940 КБ**, **никаких внешних зависимостей** и **~0% CPU в простое** (оно просыпается только для обновления каждые несколько минут).

## Возможности

| | |
|---|---|
| 🧮 **Все аккаунты сразу** | Каждый добавленный аккаунт Codex опрашивается независимо и отображается вместе с остальными - оставшийся %, время сброса, по каждому аккаунту. |
| 🔐 **Sign in with ChatGPT** | Добавляйте аккаунты прямо из приложения через официальный OAuth-процесс в браузере (PKCE). Никакой возни с `codex login`, никакой вставки токенов. Добавляйте столько, сколько захотите. |
| 📊 **Собственная мини-диаграмма в строке меню** | Отрисованная вручную графика статуса - как у системного монитора - а не мешанина из цифр. Три режима отображения (ниже). |

| ⏱️ **Живой отсчёт до обновления** | Точно видно, сколько осталось до следующего автоматического обновления; можно обновить прямо сейчас одним кликом. |
| 🌍 **4 языка** | Русский · English · 日本語 · 中文 - переключаются мгновенно из меню-шестерёнки. |
| 🪶 **Легковесное** | Нативный SwiftUI, ноль зависимостей, никакого Electron/Node/Python. Ничтожный CPU, крошечный бинарник. |
| 🔒 **Локально и приватно** | Общается только с эндпоинтами OpenAI. Учётные данные никогда не покидают ваш Mac; никакой аналитики, никаких серверов, никакой телеметрии. |

### Три режима строки меню

Выберите с помощью сегментированного переключателя внизу панели:

| Значок | Режим | В строке меню показано |
|:---:|---|---|
| 👤 | **Активный** | Аккаунт, в который сейчас залогинен Codex CLI - один индикатор + его % |
| 📊 | **Все (полоски)** | По одному индикатору на аккаунт, компактно, без цифр |
| ☰ | **Все + цифры** | По одному индикатору на аккаунт, у каждого рядом оставшийся % |

Графика в строке меню - это **шаблонное изображение** (template image), поэтому macOS тонирует её автоматически - чёткая белая на тёмной строке меню, чёрная на светлой. Внутри панели полоски остаются **цветными** (мягкий зелёный → янтарный → красный), чтобы статус считывался с первого взгляда, но не бросался в глаза кричаще.

## Установка

### Требования
- macOS 14 (Sonoma) или новее
- Xcode 16+ / тулчейн Swift 6 (для сборки из исходников)
- Установленный и хотя бы раз залогиненный [Codex CLI](https://github.com/openai/codex) (используется для инициализации вашего первого аккаунта; последующие аккаунты добавляются внутри приложения)

### Сборка из исходников
```bash
git clone <your-repo-url> codex-usage-bar
cd codex-usage-bar
./build.sh                 # → OnlyLimits.app (ad-hoc signed, dock-less)
open OnlyLimits.app
```

Установите его как любое приложение и включите автозапуск:
```bash
cp -R OnlyLimits.app /Applications/
# System Settings → General → Login Items → add OnlyLimits
```

## Использование

1. **Запустите его.** При первом запуске оно импортирует тот аккаунт, в который Codex CLI залогинен прямо сейчас.
2. **Добавьте больше аккаунтов.** Нажмите **Add account** → войдите через ChatGPT в браузере → готово. Повторите для каждого аккаунта.
   - Вход принудительно требует свежей авторизации (`prompt=login`), так что каждый раз вы можете добавить *другой* аккаунт.
   - Передумали в процессе входа? Кнопка превращается в «отмену» - один клик, и всё вернулось назад.
3. **Читайте свои лимиты.** Каждый аккаунт показывает своё окно (например, *Weekly*) в виде полоски **остатка** плюс отсчёт до сброса.
4. **Выберите режим строки меню** (👤 / 📊 / ☰) и **язык** (⚙️) - оба запоминаются между запусками.
5. **Удалите аккаунт**, нажав на 🗑 в его строке.

## Как это работает

- **Аккаунты** - это снимки логина Codex: `access_token` + `refresh_token` + `account_id`. Хранение собственного **refresh token** каждого аккаунта - вот что делает возможным независимый одновременный опрос - независимо от того, на каком аккаунте находится CLI.
- **Данные об использовании** приходят из `GET https://chatgpt.com/backend-api/wham/usage` (`Authorization: Bearer …`, `ChatGPT-Account-Id: …`). Ответ содержит `email`, `plan_type` и окна лимитов, поэтому каждый аккаунт подписывает сам себя.
- **Токены** обновляются через `POST https://auth.openai.com/oauth/token` - проактивно ближе к истечению срока и реактивно при 401 с одной повторной попыткой.
- Окна подписываются по их **фактической длительности**, поэтому приложение всегда отражает реальность (сейчас Codex предоставляет недельное окно; если вернётся 5-часовое окно, оно отобразится корректно).

## Производительность и объём

Измерено на собранном приложении в простое:

| Метрика | Значение |
|---|---|
| Размер бинарника | **940 КБ** |
| Бандл приложения | **~1 МБ** |
| Внешние зависимости | **0** |
| CPU в простое | **~0%** (просыпается только для обновления, каждые несколько минут) |
| Среда выполнения | Нативный SwiftUI / AppKit - без Electron, Node или Python |
| Иконка в Dock | Отсутствует (`LSUIElement`) - живёт исключительно в строке меню |

## Приватность и безопасность

- Общается **только** с `chatgpt.com` и `auth.openai.com`. Никаких сторонних серверов, аналитики или телеметрии.
- Учётные данные хранятся локально в `~/Library/Application Support/OnlyLimits/accounts.json` с правами `0600` - это тот же класс секретов, что уже лежит в `~/.codex/auth.json` на вашей машине.
- Ничего никуда не загружается. Всё работает на вашем Mac.
- _Дальнейшее усиление защиты:_ перенос полей с токенами в Keychain.

## Отказ от ответственности

Это **неофициальный**, независимый инструмент. Он не связан с OpenAI, не одобрен и не поддерживается ею. Он использует тот же публичный OAuth-клиент и эндпоинт использования, что и официальный Codex CLI, и предназначен **для личного использования с аккаунтами, которыми владеете вы**. Эндпоинты могут измениться в любой момент.
